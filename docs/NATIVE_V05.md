# Native0.5 · 전환 준비 성능/선택 UI/배포 크기

사용자 단독 `해`로 T70~T77 승인, 후속 EXE 용량 축소도 승인. DeX 설정 제외.

- 보기 전환마다3표 자동 폭을 재측정하던 동기 처리를 제거했다. 최초 데이터/글꼴 변경 때 원본/비교와 합쳐보기의 필요 폭을 함께 계산하고 재사용한다. 직접 편집은 변경 열의 굵은 글꼴 폭만 측정해 확장한다. 직접 조절한 열 폭은 유지한다.
- 행 높이 갱신에서 나눠보기 기본 행을 건너뛰고, 수정 행 집합을 한 번 만들어3표에서 재사용한다. 애니메이션 타일 대응은 행 위치/카드 사전으로 조회하여 셀마다 전체 행/목록을 검색하지 않는다. 원본+비교 셀 결합·수정→변경 카드 전환/스크롤 보존 유지.
- 콤보는 Qt 메뉴식 팝업을 끄고 선택 상자 아래에 목록을 배치한다. 선택 상자 텍스트/크기는 고정, 둥근 마스크/아래 펼침 유지, 공간 부족이면 위로 배치. 라이트/다크 현재 선택은 파란 바탕/흰 글자, hover는 별도 색.
- 열 연결 체크를 일반 체크박스 컨트롤 전체가 아닌 item indicator로 그려16px 영역 안에 표시한다. 미체크 테두리도 밝은/어두운 배경별 대비 확보. 전체 셀 클릭 유지.
- 파일 미선택 건수 버튼 최소80px, 연필 모양80% 축소해 원 테두리 안 여백 확보. 팝업 show/hide에서 헤더 repaint하여▼/▲ 즉시 갱신.
- PyInstaller 생성 spec에서 미사용 software OpenGL `opengl32sw.dll`과 Qt translations만 제거한다. QPainter raster Widgets 앱이며 OpenGL 위젯/Qt 번역기 사용 없음. 한글 폰트·샘플·SVG·테마 이미지·수식 엔진·설정은 유지한다. 실제 감소량과 Windows 실행 검사는 아래 배포 후 기록한다.

검증: 기존 Qt21개에 전환 시 resizeColumnsToContents 호출0/빈 건수 버튼 배치, 콤보 원위치/아래 팝업/둥근 마스크 회귀2개 추가. 이전 전환 진단은 cProfile 오버헤드 포함이며 새 비프로파일 측정값과 개선율로 직접 비교하지 않는다. 새 Qt/Linux 1회 관측은 샘플4 합치기136.3/나누기113.8ms, 샘플5(1만행)401.9/302.7ms(행 높이 추가 최적화 전, 클릭→준비+processEvents, 재생 시간 제외). Windows 실제 사용자 체감과 구분한다.

실패/보완: 기본 행 높이 갱신을 생략한 첫 시도에서 합쳐→나눠 전환의52px 높이가 남는 회귀가 발생해 모드 변경 시에는 기본 높이를 복원하도록 수정했다. 직접 편집 폭 계산이 굵은 글꼴 대비1px 부족한 회귀를 발견해 단일 수정값만 QTextDocument로 실측(HTML 굵기·여백·반올림·그리드 포함)하여 계산. Windows에서도1px 부족을 발견해 폰트 폭 근사 대신 이 경로로 통일. 스타일 추가 중 f-string 닫힘 중괄호 구문 오류는 로컬 구문 검사에서 발견해 보완했다. 변경된 앱 코드 전체 재작성 대신 프로파일로 확인된 중복 측정/검색/행 조회 경계를 개선했다.

동일 조건 비프로파일 전후 재측정: `python benchmarks/native_transition.py --source-root <소스 루트>`로0.4(1cb4c8f)/0.5를 별도 프로세스·동일 Linux/offscreen·1550×930·기본 폰트에서 실행했다. 최초 전환/역전환1회, 준비+processEvents이며 애니메이션 재생 대기 제외, 샘플 생성/초기 로드 제외. 숫자는 중앙값/Windows FPS가 아니다.

추가 최적화된 소스에서는 전환 시 resizeColumnsToContents 호출0을 회귀 검사한다. 길게 편집한 값의 폭 확장과 수동 폭 보존도 기존 회귀로 확인한다.

## Windows 배포 검증

최종 소스 `bb1e570da5177d7b64c9934d7ea27f99a4a5e9d8`, Windows 빌드41537209208 성공. Qt23개·실제 frozen EXE19항목 통과, PE64/해시와 [Windows 캡처](images/native-v05-windows.png) 확인. 로컬23개 이후 수정값 실측 보완 관련8개 재검증 통과. Windows 자체 검사 합성3열1만행 위젯177→177, 로드1.068초/순회0.009초는 CI1회 관측으로 위 실제 샘플 측정과 다른 조건이다.

EXE35,807,070bytes(34.1MiB), 이전45,277,088bytes 대비20.9% 감소. SHA256 `e82c52274e5215e1b41980a81f9ff58facbce28950da3ed745b291aa3086169f`. 한글 폰트·테마 이미지6개·샘플/CSV/XLS/XLSM/XLSX 엔진 보존. 미사용 리소스 제거 후 실제 패키지 실행·저장·수식·DPI·한글 자체 검사를 통과했다. Qt/GPU를 사용하는 별도 기능을 향후 도입하면 software OpenGL 제외 조건을 재검토한다.

사용자 Windows 실제 마우스/IME·팝업 체감 재확인은 이후 피드백 대상이며 자동 검사만으로 모두 해결됐다고 단정하지 않는다.
