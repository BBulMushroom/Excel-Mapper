# Excel Mapper 개발 프로젝트 인수인계서

## 1. 프로젝트 개요

**프로젝트명:** Excel Mapper (가칭)
**개발 목적:** 서로 다른 구조의 엑셀 파일 두 개를 비교하여 추가·삭제·수정된 데이터를 찾아내고, 사용자가 승인한 변경사항만 기존 엑셀에 반영하는 Windows용 프로그램 개발

**개발 대상:** 프로그래밍 지식이 없는 일반 직원

**개발 방향:**
- ChatGPT를 이용해 프로그램을 개발한다.
- 완성된 프로그램에는 AI 모델이나 AI API를 사용하지 않는다.
- 인터넷 없이 완전 오프라인으로 실행한다.
- Python 및 Microsoft Excel 설치 없이 실행 가능한 Windows 포터블 EXE를 목표로 한다.
- 일반 직원이 쉽게 쓸 수 있는 직관적인 GUI를 지향한다.

최초 적용 업무는 CCTV 관리대장 갱신이지만, 네트워크 장비대장, 자산관리대장 등 다른 엑셀에도 적용할 수 있는 범용 프로그램으로 개발한다.

---

## 2. 기본 업무 환경

### 원본 엑셀
- 직원이 관리 목적으로 정리해 놓은 엑셀
- 열 이름과 배치가 로우데이터와 다를 수 있음
- 셀 색상, 테두리, 열 너비 등의 서식이 존재
- 원본에만 존재하는 열도 있음
- 기존 서식을 최대한 유지해야 함

### 비교 엑셀
- CCTV 관리 프로그램 등에서 추출한 로우데이터
- 원본 엑셀과 시트명, 열 이름, 열 순서, 열 개수가 달라도 됨
- 실제 데이터는 상당 부분 중복되지만 신규·삭제·수정된 항목이 존재함

### 기본 원칙
- 병합셀은 지원 대상에서 제외
- 행 순서는 비교에 영향을 주지 않음
- 키값 기준으로 동일 데이터를 찾아야 함
- 원본과 비교본의 열 순서는 달라도 됨
- 원본에만 존재하는 열은 보존
- 기존 데이터를 불필요하게 수정하지 않음
- 수정 결과는 원본 파일을 덮어쓰지 않고 별도 저장

## 3. 핵심 기능

### 3.1 엑셀 선택 및 미리보기

사용자가 두 엑셀을 선택하면 프로그램 내부에 스프레드시트 형태로 표시한다.

**실제 Microsoft Excel을 실행하는 방식은 사용하지 않는다.**

프로그램 내부에서 다음 기능을 제공한다.

- 원본 및 비교 엑셀의 좌우 표시
- 시트 선택 및 전환
- 가로·세로 스크롤
- 열 머리글 클릭으로 열 전체 선택
- 셀 클릭 시 해당 열 선택
- 선택된 열 색상 강조
- 읽기 전용 미리보기
- 실제 데이터 확인

### 3.2 열 매핑

두 엑셀의 열 구조가 달라도 비교할 수 있도록 원본 열과 비교본 열을 연결한다.

예시:

| 원본 관리대장 | 비교본 로우데이터 |
|---|---|
| 관리번호 | DeviceID |
| 카메라명 | DeviceName |
| IP 주소 | IPv4 |
| 설치위치 | Location |

다음 세 가지 매핑 방식을 지원한다.

**① 자동 매핑**
- 열 이름 유사도 분석
- 데이터 형식 분석
- 실제 데이터 일치율 분석
- 데이터 고유값 및 중복률 분석
- 후보별 매핑 신뢰도 표시
- 자동 추천한 이유 설명
- 최종 연결 전 사용자 확인

**② 수동 매핑**
- 원본 엑셀의 열을 직접 클릭
- 비교본 엑셀에서 대응되는 열 클릭
- 두 열의 데이터 일치율 분석
- 사용자가 연결 확정
- 연결된 열은 시각적으로 표시

**③ 저장된 매핑**
- 이전에 확정한 매핑을 업무 템플릿에 저장
- 반복 작업 시 자동 불러오기
- 같은 양식이면 별도 매핑 없이 비교
- 파일명이나 파일 경로가 달라도 열 구조가 같으면 적용
- 열 구조 변경 시 재매핑 안내

자동 매핑 결과는 사용자가 수동으로 변경할 수 있어야 한다.

### 3.3 키값 매핑

같은 장비 또는 같은 데이터를 식별하기 위한 기준.

- 하나 이상의 키값 선택
- 복합키 지원
- 키값 중복 검사
- 키값 공란 검사
- 숫자·문자 형식 차이에 대한 정규화
- 앞자리 0이 중요한 관리번호 보존
- IP나 이름 등 변경될 수 있는 값을 키값으로 사용하는 경우 주의 안내

키값이 중복되거나 식별이 불가능한 경우 임의로 연결하지 않고 사용자에게 검토를 요청한다.

### 3.4 실제 데이터 일치율 분석

매핑 정확도를 높이기 위해 열 이름뿐 아니라 실제 값을 분석한다.

초기 평가 요소:
- 열 이름 유사도
- 데이터 형식 유사도
- 실제 데이터 일치율
- 고유값 비율
- 공통값 비율
- 키값 기준 동일 행의 값 일치율

초기 설계에서는 이름 20%, 형식 20%, 실제 값 60%의 가중치를 제안했으나, 아직 확정되지 않은 예시 값이다.

단순한 공통값 비율이 최종 매핑 정확도와 동일한 것은 아니다. 데이터 중복 및 변경 가능성을 고려해야 한다.

### 3.5 데이터 비교

키값으로 동일 데이터를 매칭한 후 다음 네 가지로 분류한다.

| 구분 | 의미 |
|---|---|
| 추가 | 비교 엑셀에만 존재하는 데이터 |
| 삭제 후보 | 원본 엑셀에만 존재하는 데이터 |
| 수정 | 동일 키값이지만 비교 대상 값이 다른 데이터 |
| 변경 없음 | 동일 키값이고 비교 대상 값도 동일한 데이터 |

행 순서는 비교에서 제외한다.

키값은 일치하지 않지만 이름, IP 등 다른 값이 유사한 경우 동일 장비 후보를 제시할 수 있다. 다만 유사도만으로 자동 수정하거나 병합하지 않는다.

### 3.6 변경사항 반영

두 가지 수정 단위를 지원한다.

**셀 단위:** 변경된 셀만 갱신

**행 단위:** 동일 키값에 해당하는 행에서 지정한 매핑 열들을 일괄 갱신

행 단위 수정도 원본 행 전체를 덮어쓰지 않고 원본 전용 열을 보존한다.

사용자가 변경사항을 확인할 수 있도록 다음 기능을 제공한다.

- 예
- 아니오
- 모두 예
- 변경사항 목록에서 개별 선택
- 저장 전 승인 취소 및 재검토

삭제 후보의 실제 삭제 여부는 아직 최종 확정되지 않았다. 기본 설계는 사용자 확인을 거치는 방식이다.

신규 데이터는 기본적으로 마지막 행에 추가하고 필요하면 정렬한다.

### 3.7 정렬 기능

- 정렬 안 함
- 키값 기준
- IP 주소 기준
- 이름 기준
- 사용자 지정 열 기준
- 오름차순·내림차순
- 다중 열 정렬 확장

IPv4는 문자열이 아닌 IP 숫자 순서로 정렬한다.

정렬 시에는 일부 열만 이동하지 않고 전체 데이터 행을 함께 이동하여 행 데이터가 뒤섞이지 않도록 한다.

### 3.8 변경 이력 관리

변경 이력은 별도 엑셀 시트에 저장한다.

시트 이름 예시: `20261029_131700`

색상 기준:
- 추가: 초록색
- 삭제: 빨간색
- 수정: 주황색

기록 항목:
- 변경 유형
- 키값
- 수정 대상 열
- 변경 전 값
- 변경 후 값
- 승인 및 적용 여부
- 처리 일시

기존 데이터 시트는 최대한 유지하고 변경사항만 반영한다.

## 4. 업무별 템플릿 관리

매번 같은 엑셀을 취합하는 업무는 최초 한 번만 매핑하면 된다.

### 템플릿에 저장할 항목
- 업무 프로필 이름
- 원본 및 비교 시트 선택 기준
- 제목 행과 데이터 시작 행
- 키값 매핑
- 변경값 매핑
- 행·셀 단위 수정 방식
- 신규·삭제 처리 규칙
- 데이터 정규화 규칙
- 정렬 기준
- 변경 이력 설정
- 기타 처리 옵션

### 템플릿 기능
- 신규 생성
- 복제
- 수정
- 삭제
- 이름 변경
- 자동 불러오기
- 이전 설정 재사용

설정 파일은 내부적으로 INI 등을 활용할 수 있지만, 사용자에게 설정 파일을 직접 수정하도록 요구하지 않는다.

일반 사용자는 작업 카드나 템플릿 목록에서 업무를 선택한다.

## 5. UI 설계

개발자용 설정 화면보다 일반 사용자가 이해하기 쉬운 형태를 우선한다.

### 메인 화면
- CCTV 관리대장 갱신
- 네트워크 장비대장 갱신
- 자산관리대장 갱신
- 새 작업 만들기
- 최근 작업

### 신규 작업 설정
단계별 마법사 형태로 구성한다.

1. 원본·비교 엑셀 선택
2. 시트 및 데이터 범위 확인
3. 키값 지정 및 열 매핑
4. 변경 처리 규칙 설정
5. 템플릿 저장

### 반복 작업
저장된 템플릿 선택 후 다음 네 단계로 진행한다.

1. 엑셀 두 개 선택
2. 자동 비교
3. 변경사항 확인
4. 결과 저장

### GUI 원칙
- 코딩 관련 용어 최소화
- 실제 엑셀 형태의 데이터 표시
- 직접 클릭하는 방식 우선
- 오류 원인과 해결 방법 안내
- 안전한 작업을 위한 미리보기
- 작업 진행 상태 표시
- 복잡한 기능은 고급 설정으로 분리

## 6. 기술 구성

현재 권장 기술:

| 구성 요소 | 기술 |
|---|---|
| 개발 언어 | Python |
| GUI | PySide6 |
| 스프레드시트 표시 | QTableView / QAbstractTableModel |
| 엑셀 처리 | openpyxl |
| 문자열 유사도 | RapidFuzz 등 |
| 설정 관리 | INI 또는 SQLite |
| Windows 배포 | PyInstaller |

외부 AI 서비스와 API를 사용하지 않는다.

Windows용 EXE를 최종 목표로 하되, Windows 빌드 및 실행 테스트가 필요하다.

## 7. 프로토타입 개발 상황

이전 채팅에서 **Excel Mapper v0.1**이라는 ZIP 형태의 프로토타입을 제공했다.

제공 당시 안내한 주요 기능:
- 엑셀 파일 선택
- 좌우 데이터 표시
- 열 클릭 선택
- 키값 및 변경값 연결
- 공통값 기반 일치율 표시
- 자동 매핑 추천
- 비교 결과 미리보기
- 매핑 저장·불러오기

이전 프로토타입은 Python 실행 환경을 전제로 제공되었다.

실제 원본 엑셀 수정과 최종 결과 저장은 미구현으로 안내되었다.

**새 채팅에서는 해당 ZIP 파일을 다시 첨부해야 기존 코드를 확인하고 이어서 수정할 수 있다.** 파일이 없으면 본 문서의 요구사항을 바탕으로 새로 구현한다.

- 데이터 일치율 기반 열 자동 추천

- 업무별 매핑 규칙의 반복 사용
- 관리대장 서식을 유지한 변경사항 반영

## 11. 새 채팅의 AI 개발 담당자에게 요청

당신은 AX 전환 업무를 담당하는 20년 차 소프트웨어 기획자이자 Python GUI 개발자다.

위 내용을 기존 프로젝트의 요구사항으로 이해하고, 사용자와 함께 Excel Mapper를 지속 개발해야 한다.

개발 시 다음 원칙을 지킨다.

- 프로그램에 AI를 탑재하지 않는다.
- 인터넷 연결이 필요 없는 오프라인 프로그램으로 개발한다.
- 일반 직원의 사용 편의성을 최우선으로 한다.
- 설정과 매핑은 가능한 한 실제 엑셀 화면에서 클릭하는 방식으로 구현한다.
- 자동 매핑과 수동 매핑을 모두 제공한다.
- 실제 데이터 일치율 분석을 중요하게 취급한다.
- 최초 설정 후 반복 작업을 최소화한다.
- 원본 엑셀 훼손을 방지한다.
- 프로그램 개발 시 소스코드만 설명하기보다는 실행 가능한 결과물을 제공한다.
- 기존 코드가 첨부되면 해당 버전을 기반으로 개선한다.
- 기능 추가 및 수정 때마다 버전 번호를 증가시킨다.
- 추가 요구사항이 나오면 기존 설계와 충돌하는지 먼저 검토한다.

**현재 우선 과제는 v0.1 프로토타입을 기반으로 실제 사용자가 편리하게 열을 선택하고 매핑할 수 있는 GUI를 개선하는 것이다.**
