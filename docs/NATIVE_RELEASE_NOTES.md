Excel Mapper 1.000 — **ExcelMapper.exe 한 파일**을 실행합니다(설치 필요 없음, Windows 64비트, 인터넷 연결 불필요).

- **비교와 반영**: 열 이름과 순서가 다른 엑셀도 기준 키로 행을 맞춰 추가·수정·삭제를 보여 주고, 승인한 변경만 원본 서식 그대로 새 파일에 저장합니다. 셀 단위와 행 단위 합치기, 셀 직접 편집, 실행 취소를 지원합니다.
- **여러 파일 취합**: 여러 회신 파일을 순서대로 검토하며 `반영 후 다음`으로 누적 반영합니다.
- **열 연결**: 열 이름 검색, 보기 필터, 보이는 열 일괄 연결·해제를 지원합니다.
- **병합 셀과 구조 행**: 대분류·중분류 병합, 소계·총계·결재란을 인식해 엑셀처럼 보여 주고, 행 추가·삭제 시 병합 범위와 수식 범위를 함께 조정합니다. 새 행은 행 번호 칸을 끌어 위치를 정합니다.
- **변경 이력**: 결과 파일에 실제로 반영한 변경만 셀마다 한 줄로 기록합니다(변경 유형·키값·대상 열·변경 전·변경 후·위치·비교 파일·처리 일시).
- **화면**: 나눠보기·합쳐보기, 엑셀식 열·행 숨기기, 필터·정렬·검색, 테마와 글꼴 설정, 프리셋, 테스트 샘플 10종.
- **오류 안내**: 문제가 있는 파일·시트·행·열 위치와 해결 방법을 함께 안내합니다.
- **명령줄 모드**: 화면 없이 같은 엔진으로 비교·저장합니다(`ExcelMapper.exe --compare 원본 비교 --out 결과`).
- 아직 지원하지 않는 것: 병합된 칸의 값 수정 저장, 병합·소계가 있는 시트에서 정렬해 저장, 2단 제목(제목 행 병합), 소계 수식의 화면 실시간 계산.

Windows 자체 검사(EXE 실행·명령줄 모드·파일 속성 확인 포함)와 회귀 테스트로 검증했습니다.
